# 🌱 Agentic AI-Based Incentive Waste Management System

## 📌 Project Overview

The **Agentic AI-Based Incentive Waste Management System** is an AI-powered platform designed to encourage responsible waste segregation and recycling through intelligent waste classification and reward-based incentives.

The system allows users to upload images of waste, which are analyzed using an AI vision model to identify the waste category. Based on the classification, reward points are suggested. Submitted waste is then sent for human verification. Once approved, the corresponding eco-points are credited to the user's account.

The platform also provides a user dashboard, submission history, leaderboard, and an AI-powered recycling assistant to promote environmental awareness and sustainable waste management practices.

## 🎯 Objectives

- Automate waste identification using AI-based image classification.
- Encourage proper waste segregation and recycling.
- Introduce an incentive-based reward system.
- Provide human verification before awarding points.
- Track user contributions through points and submission history.
- Promote environmental awareness through an AI-powered assistant.

## ✨ Key Features

- **AI Waste Classification:** Identifies waste categories from uploaded images.
- **Waste Submission:** Allows users to submit waste images for analysis.
- **Human Verification:** Supports approval or rejection of submitted waste.
- **Eco-Reward System:** Awards points for approved waste submissions.
- **User Dashboard:** Displays eco-points, levels and activity information.
- **Submission History:** Maintains records of user waste submissions.
- **Leaderboard:** Displays user rankings based on earned points.
- **AI Recycling Assistant:** Provides information and guidance about recycling and waste management.

## ⚙️ System Workflow

1. User uploads an image of waste.
2. AI vision model analyzes the image.
3. System identifies the waste category and suggests reward points.
4. Submission is stored for verification.
5. Reviewer approves or rejects the submission.
6. Approved submissions receive eco-points.
7. Dashboard updates user points and submission history.
8. Leaderboard reflects user performance.
9. AI assistant provides recycling guidance.
